# RIMBARA AI V8.3 — DEMO GRATIS

Versi demo ini **tidak memanggil OpenAI API**, sehingga tidak membutuhkan saldo/kredit API.

Fitur demo:
- Tutor Raka / Rara
- British English via speech synthesis browser
- Topik Daily Conversation, Forestry English, PKL / Field Practice, Job Interview
- Slow Mode
- Voice input otomatis bila browser mendukung SpeechRecognition
- Kotak ketik sebagai fallback bila voice input browser tidak tersedia
- Transcript dan feedback lokal sederhana
- Avatar speaking animation

## Deploy ke Vercel / GitHub
Salin isi folder ini ke root repository dan pastikan `index.html`, `app-v7.js`, `style-v7.css`, dan `assets/` berada di root.
API OpenAI tidak diperlukan untuk menjalankan demo.
