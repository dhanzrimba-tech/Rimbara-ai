# RIMBARA AI V5
Live Conversation prototype for British English speaking practice.

V5 adds:
- Live chat-style conversation flow
- Voice input using browser speech recognition
- British English speech output preference
- Slow listening mode
- Forestry English / PKL / Job Interview topics
- Speaking feedback panel
- Production backend architecture notes

Important: this package is a functional front-end prototype, not yet a production cloud AI service. Real AI conversation and premium British voices require a secure backend and provider credentials.
