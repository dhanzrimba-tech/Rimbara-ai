# RIMBARA AI V2.5 — Bilingual Conversation Demo

Peningkatan dari V2.4 Mobile Fix.

## Fitur utama
- Tutor Raka/Rara tetap terlihat di sisi percakapan saat chat bertambah panjang (sticky tutor rail).
- Pada HP, tutor menjadi mini sticky tutor bar di atas area percakapan.
- Setiap ucapan tutor tampil dalam Bahasa Inggris + arti Bahasa Indonesia.
- Ada toggle untuk menampilkan/menyembunyikan arti Bahasa Indonesia.
- Animasi status tutor tetap berjalan: READY, LISTENING, THINKING, SPEAKING, APPLAUSE.
- Demo voice tetap menggunakan audio lokal tanpa OpenAI API.
- Layout tetap touch-friendly untuk HP.

Catatan: terjemahan otomatis untuk kalimat bebas siswa belum menggunakan AI pada mode demo gratis; arti yang disediakan penuh adalah untuk dialog tutor yang sudah disiapkan.
