# RIMBARA AI V6

V6 is the first integration-ready version:
- Secure server-side OpenAI Responses API connection
- Natural conversation tutor prompt
- Raka/Rara personas
- Daily, Forestry, PKL and Job Interview topics
- British English TTS endpoint
- Front-end health indicator
- Browser fallback remains available
- API key stays server-side

The Responses API is the recommended API for new OpenAI projects, and OpenAI's current audio APIs include text-to-speech and realtime speech options. For a true low-latency voice-to-voice experience, the next stage can use the Realtime API over WebRTC.
