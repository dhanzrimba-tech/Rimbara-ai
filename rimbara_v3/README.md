# RIMBARA AI V3
AI English Speaking Tutor — SMK Kehutanan Rimba Bahari Sumedang.

## V3 changes
- Raka male avatar + Rara female avatar.
- Original school logo retained in the app.
- Character voice mode uses browser English voices with different pitch for Raka/Rara.
- Added a **Suara saya — contoh rekaman** mode using the cleaned personal voice sample supplied for this project.
- Microphone speech recognition, scenario selection, speaking feedback, and animated speaking state.

## Important voice note
The personal recording is included as a reference/sample only. A browser cannot turn an arbitrary WAV recording into unlimited new sentences in that same voice by itself. For true AI voice cloning, connect an approved voice-AI provider/backend and use the supplied recording only with the speaker's consent.

## Run
Open `index.html` in a modern browser. Microphone features generally require HTTPS or localhost.
