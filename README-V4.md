# RIMBARA AI V4 — British English Conversation Prototype

V4 focuses on a natural speaking-learning flow:
- Raka (male) and Rara (female) tutor modes
- British English (`en-GB`) speech preference
- Natural-rate and slow speaking modes
- Browser speech recognition for student practice
- Transcript and simple speaking feedback
- Forestry / school-oriented conversation prompt

This is still a front-end prototype. A production version should connect a secure backend to a real conversational AI, high-quality licensed British voices, and a proper pronunciation-scoring engine. API keys should never be placed directly in the browser.
