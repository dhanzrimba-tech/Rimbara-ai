# RIMBARA AI V7.1 — QUICK START

```bash
cd server
npm install
copy .env.example .env
npm start
```

Then serve the frontend from another terminal:

```bash
python -m http.server 8080 --directory rimbara_v3
```

Open `http://localhost:8080`.

After a voice session, click **Analyse My Speaking** to generate supportive feedback.
