# RIMBARA AI V5 Backend Starter

The browser prototype currently uses Web Speech APIs for demonstration. For a production AI tutor:
1. Send the student's transcript/audio to a secure backend.
2. Backend calls the selected conversational AI model.
3. Backend requests licensed British English speech.
4. Return the tutor response/audio to the browser.
5. Keep all API keys server-side.

Do not put secret API keys in `index.html`.
